About this Demo

This application demonstrates Identity and Access Management (IAM) using Keycloak and OpenID Connect.

Features:

  • Public Page: Accessible without authentication
  • Protected Page: Requires authentication via Keycloak
  • User Information: Displays data extracted from the ID Token
  • OpenID Connect Code Flow: Secure authorization flow

Security Concepts:

  • Confidentiality: Secure authentication via OAuth2/OIDC
  • Integrity: Cryptographically signed JWT tokens
  • Availability: Centralized identity management
