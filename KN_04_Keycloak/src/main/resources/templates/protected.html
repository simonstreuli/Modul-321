About This Page

This page is protected and can only be accessed after successful authentication through Keycloak using the OpenID Connect Code Flow.

Security Features Demonstrated:

  • Authentication: Verified user identity via Keycloak
  • Authorization: Access control based on authentication state
  • Token-based Security: JWT tokens for secure information exchange
  • Code Flow: OAuth 2.0 Authorization Code Flow with PKCE

What Happened:

  1. You clicked "Login" and were redirected to Keycloak
  2. You entered your credentials in Keycloak's login page
  3. Keycloak authenticated you and issued an authorization code
  4. The application exchanged the code for an ID Token and Access Token
  5. The application validated the tokens and extracted your user information
  6. You were granted access to this protected page
